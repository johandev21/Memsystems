# Ayuda y soporte

Antes de pedir ayuda:

1. Revisa el [README](README.md) y la documentación en `docs/`.
2. Busca issues existentes por el mensaje de error o el comportamiento observado.
3. Comprueba que tu configuración y dependencias correspondan a la versión que ejecutas.

Para pedir ayuda sobre un problema de uso o configuración, abre un issue e incluye:

- Qué intentabas hacer y qué ocurrió.
- Los pasos mínimos para reproducirlo.
- Sistema operativo, versión de Node.js, pnpm y forma de ejecución (local o Docker).
- Mensajes de error relevantes, con secretos, tokens, URLs privadas y datos personales eliminados.

Usa el formulario de reporte de error si sospechas que el comportamiento es un defecto del proyecto. Para proponer una mejora, usa el formulario de solicitud de funcionalidad. No uses issues públicos para reportar vulnerabilidades; sigue [SECURITY.md](SECURITY.md).

Memsystems es un proyecto en desarrollo y no ofrece soporte con tiempos de respuesta garantizados.
