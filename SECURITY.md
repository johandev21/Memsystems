# Reportar una vulnerabilidad

No publiques vulnerabilidades de seguridad en issues, discusiones ni pull requests públicos. Usa la opción **Report a vulnerability** de la pestaña **Security** de este repositorio para enviar un reporte privado a sus responsables.

Incluye, cuando sea posible, los pasos para reproducir el problema, su impacto y las versiones o configuraciones afectadas. Evita adjuntar secretos activos o datos personales; usa ejemplos sintéticos.

El proyecto es una aplicación local de usuario único que puede almacenar claves de proveedores y datos importados. No asumas que una instalación está expuesta de la misma forma que otra; explica las condiciones necesarias para reproducir el impacto.

No hay un plazo de respuesta garantizado. Si la opción de reporte privado no está disponible, consulta a las personas responsables del repositorio antes de divulgar detalles técnicos públicamente.
